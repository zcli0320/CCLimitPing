# Codex 小助手 0.5.0 / build 48

本版将账号、会话与协作功能整理为四个原生工作区：概览、账号与额度、会话与续跑、项目协作。采用 NavigationSplitView、SF Symbols、原生工具栏、Settings 与菜单快捷键。

- 设置集中管理通用、启动与恢复、协作选项。
- 项目任务列表与详情分区呈现，区分执行、排队与待验收；窄窗口支持返回列表。
- 项目创建与任务派发统一进入工具栏，项目规则、编辑与归档放入项目操作菜单。
- 保留原有账号数据、Desktop/CLI 分区、CC Switch 归属和单会话续跑授权边界。
- 最低系统要求调整为 macOS 13。安装前请退出旧版小助手，解压后将应用放入原安装位置。

下载包按构建机器架构命名，请选择与 Mac 匹配的版本。公开构建使用临时签名，未经过 Apple 公证；更新后可能需要重新授予已有系统权限。本机固定签名构建保留在本地 dist 目录。

验证包含原生构建与签名、Swift 状态及协作测试、隔离窗口与工具栏检查。macOS 13 最低版本通过编译和二进制标记核验；未在 macOS 13 实机测试。自然额度耗尽后的真实账号交接仍未完整实机验收。
